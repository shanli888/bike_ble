# LVBU Web 智能码表 — Bluefy Web Bluetooth

纯静态单页 HTML，零依赖，在 Bluefy 中打开即可连接 LVBU 电机控制器。

## 蓝牙协议（LVBU 3.4.0 已确认）

依据原厂 APK `wang.lvbu.mobile` 3.4.0 逆向分析确认。

### 连接

- 服务：`FFE0`（0000ffe0-0000-1000-8000-00805f9b34fb）
- 命令写入 / 通知：`FFE1`（同一特征，双向）
- 控制 / 重启：`FFE2`（单字节 `33`）

### 命令帧

```
<命令码>F<15位电机IMEI>[<数据>]   ->   hex 字符串转原始字节写入 FFE1
```

- 字节是通过 `string2Hex` 将 hex 字符串转成原始字节（**不是 ASCII**）。
- 例如电压查询 `C0F866855030090179` -> 字节 `C0 F8 66 85 50 30 09 01 79`。
- IMEI 是**电机 IMEI**（本车固定 `866855030090179`），不是手机 IMEI。

### 回复帧

回复以十六进制字符串形式返回（FFE1 通知字节转 hex），命令码 + IMEI 用于匹配。

- 电压 `C0`：24 个十六进制字符，状态在第 19-20 位，末四位**十进制**除以 10 得电压（`0385` -> 385 -> 38.5 V）。
- 速度 `BF`、温度 `C1`、陀螺仪 `BD`、里程 `B1` 格式相似，数值均按十进制解析。

### 命令表

| 功能 | 命令字 | 说明 |
| --- | --- | --- |
| 电压查询 | `C0` | 读 |
| 速度查询 | `BF` | 读 |
| 温度查询 | `C1` | 读 |
| 里程查询 | `B1` | 读 |
| 陀螺仪查询 | `BD` | 读 |
| 设置助力模式 | `C4` | 写，模式码：01 手动 / 02 休闲 / 03 运动 / 04 通勤 / 05 爬坡 |
| 设置轮胎周长 | `AB` | 写，4 位十进制 mm |
| 陀螺仪校准 | `BE` | 写 |
| 重启 | `33` | FFE2 写单字节 |

> 手动功率百分比 `A5` 因原厂 100% 边界有疑，当前不启用（滑块保持禁用）。

## 使用

1. 将 `lvbu-ble` 发布到静态站点（GitHub Pages 等）
2. Bluefy 打开页面
3. 设备页点击「选择设备」→ 在系统弹窗中选 LvBu motor
4. 连接后码表页自动查询电压 / 速度 / 温度 / 陀螺仪

## BR80 闪控（LIVALL）

可与助力控制器**同时连接**，用闪控按键调助力。

### GATT

| 用途 | UUID |
| --- | --- |
| 服务 | `0000A2A0-0000-1000-8000-00805F9B34FB` |
| 写入 | `0000A2A3` |
| 通知 | `0000A2A4` |
| 电量 | `180F/2A19`（标准电池服务） |

### 关键：连接后必须先激活

向 **A2A3 写单字节 `0xFF`**（原厂日志 `rockWrite:`），并对 A2A3 也开启通知。
不做这一步，闪控不会推送按键。

### 按键协议（BR80 直连，A2A4 单字节）

| 字节 | 按键 | 字节 | 抬起 |
| --- | --- | --- | --- |
| `0x05` | ▼ 下 | `0x25` | ▼ 抬起 |
| `0x06` | ▲ 上 | `0x26` | ▲ 抬起 |
| `0x07` | ◀ 左 | `0x27` | ◀ 抬起 |
| `0x08` | ▶ 右 | `0x28` | ▶ 抬起 |
| `0x09` | ● 主键 | `0x29` | ● 抬起 |

注意：`55AA...` 长帧属于头盔 SPP 路径，BR80 直连不用。

### 行为

- ▲ / ▼：助力 ±步进值，立即下发
- ● 主键：停止助力（0%），记录原值
- 停止后按 ▲/▼：恢复原助力值
- 每次按键后冻结 5 秒，防误触连发
- 电量取通知串末 2 字符按十六进制解析，`88` 表示充足

## 安全提示

- 助力调整与模式切换可随时进行（无停车限制），请自行判断骑行安全。
- 陀螺仪校准仍需停车（会改变电机标定）。
- 电机 IMEI 属于敏感信息，勿公开分享。
